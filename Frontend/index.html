Frequently asked questions

Make an informed start.

Which endpoints and models are available?

Browse the model catalog for published capabilities and rates. The API guide lists supported endpoints. Use a model marked Ready for the corresponding request type; availability can change.

How is API usage billed?

Rates vary by model and workload. Review the published input and output rates, then see pricing and billing details for how usage is charged to your account balance.

How do I create and secure an API key?

Create a key from API key settings. Store it in a server-side environment variable or secret manager, and never embed it in frontend/browser code or a public repository. See the integration guide.

What if a model or endpoint is unavailable?

Check the service status page for reported telemetry and choose a model marked Ready in the catalog. Handle unsuccessful API responses in your application; status data may not be available for every model.

Where can I get help with an integration?

Start with the API integration guide. For deployment, volume or enterprise questions, send the team a message below.
