Human Language Syntax Guide

This guide is a practical reference for writing Human programs in v0.1.8. The examples below reflect the current runtime behavior and the most useful syntax patterns.

1. Comments

-- This is a single-line comment

2. Variables and values

set name to "Ada"
set age to 37
set active to true
set score to 99.5

3. Printing and input

print "Hello, Human!"
print name
ask "What is your name?"

4. Operators

Arithmetic

set sum to 10 + 5
set product to 3 * 4
set remainder to 10 % 3

Comparison

if age is greater than 18 then
    print "Adult"
end if

Logical operators

if age is greater than 18 and active is true then
    print "Ready"
end if

5. Control flow

If / else

if score is greater than 90 then
    print "Excellent"
else
    print "Needs improvement"
end if

Loops

loop from 1 to 5 do
    print "Hello"
end loop

6. Functions

define greet with name
    return "Hello, " + name
end define

print greet("Ada")

7. Lists, dicts, and strings

set nums to [1, 2, 3]
set user to {name: "Ada", age: 37}

print call list_first with nums
print call dict_get with user, "name"

8. Type annotations

function add with a: int, b: int -> int
    return a + b
end function

9. Generics

function<T> first_item with items: List<T> -> T
    return items[0]
end function

10. Pattern matching and destructuring

set [first, second, third] to [10, 20, 30]
set {name, age} to {name: "Ada", age: 37}

11. Standard library examples

set text to "hello world"
print call string_upper with text
print call string_replace with text, "world", "Human"
print call math_average with [1, 2, 3, 4]

12. Web framework examples

from human_language.vm import VM, Bytecode

vm = VM(Bytecode())
vm.web_controllers["home"] = lambda request: vm.text_response("Hello")
vm.route("GET", "/", "home")

Common web helpers

vm.ok({"ok": True})
vm.created({"id": 1})
vm.not_found({"detail": "missing"})
vm.html_response("
Hello
")
vm.redirect("/login")

13. Database and persistence

call db_connect with "app.db", "default"
call orm_register_model with "users", {"id": "INTEGER PRIMARY KEY", "name": "TEXT"}
call orm_create with "users", {"name": "Ada"}

14. Python interop

set np to py_import("numpy")
set arr to py_call(np, "array", [[1, 2, 3]])

15. Recommended style tips

  • use clear names such as user_name instead of x
  • keep functions focused on one task
  • use comments to explain non-obvious logic
  • break larger programs into small pieces
  • start with scripts, then add web routes and persistence
