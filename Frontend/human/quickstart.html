Quickstart

Install Human, write your first program, and build a small web service.

Quickstart Syntax Features Releases

Install and run Human

pip install human-language
human hello.hm

Your first program

print "Hello, Human!"

set age to 25
if age is greater than 18 then
    print "You are an adult"
end if

Build a small web API

from human_language.vm import VM, Bytecode

vm = VM(Bytecode())
vm.web_controllers["home"] = lambda request: vm.text_response("Hello from Human")
vm.route("GET", "/", "home")
