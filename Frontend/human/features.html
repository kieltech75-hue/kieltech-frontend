Quickstart Syntax Features Releases

Runtime capabilities

  • Readable scripts, functions, conditionals, loops, types, generics, and pattern matching.
  • Standard-library helpers for strings, lists, dictionaries, math, and JSON.
  • Built-in web routing, middleware, sessions, uploads, downloads, and OpenAPI documentation.
  • SQLite and ORM-style data access with transactions and migrations.
  • Runtime-native DOM, events, styling, layout, reactivity, storage, and history helpers.
  • Python interoperability for trusted integrations.

Web runtime example

from human_language.vm import VM, Bytecode

vm = VM(Bytecode())
root = vm.dom_create_element("div", {"id": "app"})
vm.dom_set_text(root, "Hello, Human")
