Human Language v0.1.8

A major step forward for Human with full-stack runtime capabilities, richer web features, and stronger developer tooling.

Overview

Human v0.1.8 marks a significant expansion of the runtime with production-ready web framework features, browser-competitive frontend capabilities, and professional backend tooling. This release positions Human as a full-stack, runtime-native platform for building complete applications without external framework scaffolding.

What's New

Web Framework & Backend

  • Built-in HTTP routing with GET, POST, PUT, DELETE, and other HTTP methods
  • Middleware support for request processing, validation, and error handling
  • Session and authentication helpers with secure cookie handling
  • Request/response handling with JSON, form data, and file upload support
  • Validation middleware for schema validation and type checking
  • Rate limiting and request logging for production applications
  • OpenAPI documentation auto-generation and swagger UI
  • ASGI compatibility for deployment to production servers

Frontend Layer

  • DOM API for creating and manipulating elements
  • Event system with event listeners and propagation
  • CSS-like styling with cascade and inheritance
  • Layout primitives for responsive design
  • Reactivity for automatic UI updates
  • Browser storage helpers for localStorage and sessionStorage
  • History API for navigation and back/forward support
  • Hot reload support in development mode

Data & Database

  • SQLite integration with ORM-style helpers
  • Model registration and schema definition
  • CRUD operations (create, read, update, delete)
  • Transaction support for data consistency
  • Migration helpers for schema evolution
  • Query builders for common operations

Developer Experience

  • Improved REPL with module catalog and helper discovery
  • CLI enhancements for running scripts and starting dev servers
  • Windows installers (64-bit, 32-bit, and web-based)
  • Comprehensive error messages and debugging output
  • Hot-reload dev server for rapid development

Runtime Quality

  • Expanded test suite with 83+ regression tests
  • Backend ergonomics tests for framework consistency
  • Auth and session behavior validation
  • Validation middleware testing
  • DB and ORM integration tests

Installation

Windows

Download the appropriate installer for your system:

  • 64-bit: human-language-0.1.7-x64-setup.exe
  • 32-bit: human-language-0.1.7-x86-setup.exe
  • Web-based: human-language-0.1.7-web-setup.exe

From PyPI

  • pip install human-language
  • python -m pip install human-language

From source

  • git clone https://github.com/kieltech2/Human.git
  • cd Human
  • python -m pip install -e .

Key Features

Full-Stack in One Runtime

Instead of splitting work across separate HTML, CSS, JavaScript, and backend frameworks, Human brings routing, state, DOM updates, styling, and interaction together in one coherent platform.

Production-Ready Defaults

  • Secure session handling with configurable timeouts
  • Built-in rate limiting and request logging
  • Input validation and error handling
  • OpenAPI documentation for API introspection

Easy to Learn

Human's English-like syntax remains beginner-friendly while supporting professional runtime capabilities.

Breaking Changes

None. This is a forward-compatible release.

Known Limitations

  • 32-bit Windows installer is for legacy systems only; 64-bit is recommended
  • Web-based installer requires internet connectivity during setup
  • Some advanced features may differ from established Python web frameworks

  • Expanded standard library
