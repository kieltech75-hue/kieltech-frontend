Human Quick Start Guide

Welcome to Human v0.1.8. This guide is designed to help you learn the language step by step, from the basics to the more powerful features that make Human useful for real applications.

1. Install and run Human

Install from PyPI

pip install human-language

Run a program

human hello.hm

2. Your first program

Create a file named hello.hm:

print "Hello, Human!"

Run it:

human hello.hm

3. Variables, conditionals, and loops

set age to 25

if age is greater than 18 then
    print "You are an adult"
else
    print "You are under 18"
end if

loop from 1 to 3 do
    print "Hello"
end loop

4. Functions and return values

define greet with name
    return "Hello, " + name
end define

print greet("Ada")

5. Lists, dicts, and standard library helpers

set nums to [1, 2, 2, 3]
print call list_unique with nums

set user to {name: "Ada", age: 37}
print call dict_get with user, "name"
print call string_upper with "human"

6. Type annotations and generics

function add with a: int, b: int -> int
    return a + b
end function

function<T> first_item with items: List<T> -> T
    return items[0]
end function

7. Pattern matching and destructuring

set [first, second, third] to [10, 20, 30]
set {name, age} to {name: "Ada", age: 37}

print first
print name

8. Build a tiny web API

from human_language.vm import VM, Bytecode

vm = VM(Bytecode())
vm.web_controllers["home"] = lambda request: vm.text_response("Hello from Human")
vm.route("GET", "/", "home")

Helpful response helpers

vm.ok({"ok": True})
vm.created({"id": 1})
vm.not_found({"detail": "missing"})
vm.html_response("
Hello
")
vm.redirect("/login")

9. Use a database

call db_connect with "app.db", "default"
call orm_register_model with "users", {"id": "INTEGER PRIMARY KEY", "name": "TEXT"}
call orm_create with "users", {"name": "Ada"}

10. Add auth and security helpers

set cookie = call build_secure_cookie with "session_id", "abc123"
set token = call create_jwt with {user_id: 1}, "secret", 3600

11. Python interop when you need it

set np to py_import("numpy")
set arr to py_call(np, "array", [[1, 2, 3]])

12. Learn in the right order

  1. Learn the core syntax and basic control flow.
  2. Practice functions and standard-library helpers.
  3. Add type annotations and generics.
  4. Move to web APIs and routes.
  5. Add persistence, auth, and Python integrations.

13. Signed Cookies & CSRF

# Sign a value
set signed_token = call sign_value with "my-secret", "user123"

# Verify signed value
set verified = call verify_signed_value with "my-secret", signed_token

# Build secure cookie
set cookie = call build_secure_cookie with "session_id", "abc123"
# Sets: session_id=abc123; Path=/; HttpOnly; Secure; SameSite=Lax

# Generate CSRF token
set csrf = call generate_csrf_token with session_id

# Verify CSRF token
set is_valid = call verify_csrf_token with session_id, csrf

14. API Documentation (OpenAPI)

# Define route with schema
call route with "POST", "/users", "create_user", 
  {"name": {"type": "str", "required": true}, 
   "email": {"type": "str", "required": true}}

call route with "GET", "/users/{id}", "get_user"

# Generate OpenAPI spec
set spec = call generate_openapi with "My API", "1.0.0"
# Returns OpenAPI 3.0 specification with request/response schemas
